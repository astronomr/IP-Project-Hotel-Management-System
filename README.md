The “Hotel Management System” is a management software for allowing users to book Hotel rooms and maintain their records.
The DMS is a menu-based application developed in Python (Spyder) with the backend of a comma-separated value (CSV) flat file.
Libraries used - Pandas, matplotLib

This project has been made without the use of functions as per the requirements of the subject - Informatics Practices (IP)

For more information, check 'IP Project File.pdf' attached to the repository.

The following menu options are available to the User:
1. Book their Hotel room.
2. Login/Register to confirm their bookings.
3.Viewing the rooms they have booked.
4.Cancelling the rooms they have booked.

If User is an Admin,
1.They can view all rooms booked by different people.
2.Viewing which Hotel / Room Type / Facilities is most popular using Graphs.
3.Managing User bookings and User data.
